\# Matrix Registration CI/CD Project



This project is a Python application that validates user input and performs matrix operations using NumPy.



\## Features

\- Phone number validation

\- ZIP+4 validation

\- Matrix addition

\- Matrix subtraction

\- Matrix multiplication

\- Element-by-element multiplication

\- Matrix transpose

\- Row and column mean calculations



\## Technologies Used

\- Python

\- NumPy

\- Pytest

\- GitHub Actions



\## CI/CD Pipeline

The pipeline automatically installs dependencies and runs tests whenever code is pushed to the main branch or a pull request is created.



\## Run the App

```bash

python app/matrix\_app.py
